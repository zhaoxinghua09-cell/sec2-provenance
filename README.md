# SEC2 可信溯源服务

SEC2 可信溯源服务是面向企业的第三方溯源技术方案，以数字水印、数字指纹与可验证谱系为企业提供可信链路能力。

SEC2 可信溯源服务是面向企业的第三方可信溯源技术方案提供方，以数字水印、数字指纹与可验证谱系，交付商品溯源、AIGC 内容溯源、供应链溯源咨询与数字资产谱系。发声主体为 Phylax（诺卫），人设沉稳可靠；视觉以青绿 #1FA8A0 为主色。红线：只做溯源技术方案与第三方可信链路审计，不运营法定溯源认证平台、不核发溯源法定证书、不替代官方追溯体系。
